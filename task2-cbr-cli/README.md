# Task 2 — Async CLI-аналитик курсов валют ЦБ РФ

Python-утилита командной строки: асинхронно загружает курсы валют с публичного
API ЦБ РФ, считает производные значения (суточная динамика, топ движений,
агрегаты) и выводит структурированный отчёт в консоль с экспортом в CSV/JSON.

## Что делает

- Запрашивает курсы с `https://www.cbr-xml-daily.ru/daily_json.js` (JSON, без авторизации).
- Считает по каждой валюте: абсолютную суточную дельту, процент изменения, направление.
- Формирует сводку: среднее изменение, сильнее всех укрепившаяся / ослабшая валюта.
- Печатает выровненную таблицу и топ-N движений за сутки.
- Сохраняет результат в CSV или JSON.

## Архитектура

Проект построен по принципам GRACE: каждый модуль имеет контракт, ООП-структуру
и зону ответственности.

| Модуль | Файл | Ответственность |
|---|---|---|
| Config | `cbr_cli/config.py` | Типизированная конфигурация из окружения |
| Errors | `cbr_cli/errors.py` | Иерархия исключений → коды возврата |
| Domain | `cbr_cli/domain.py` | Неизменяемые модели + валидирующий парсер ответа API |
| CbrClient | `cbr_cli/cbr_client.py` | Async HTTP-клиент с retry и экспоненциальным backoff |
| RateAnalyzer | `cbr_cli/analytics.py` | Расчёт дельт, топ движений, агрегатов |
| Reporter | `cbr_cli/report.py` | Консольная таблица и экспорт в CSV/JSON |
| Cli | `cbr_cli/__main__.py` | Точка входа: argparse, оркестрация, exit codes |

**Устойчивость:** асинхронный ввод-вывод (`httpx.AsyncClient`), retry с backoff и
таймаутом, строгая валидация формата ответа, иерархия исключений вместо «голых»
`except`, типизация и неизменяемые модели, 32 теста с замоканным HTTP (`respx`).

## Запуск через Docker (рекомендуется)

```bash
# 1. Собрать образ
docker build -t cbr-cli .

# 2. Запустить с сохранением экспорта в локальную папку ./output
docker run --rm -v "${PWD}/output:/app/output" cbr-cli --format csv --top 5

# 3. Только вывод в консоль, без файла
docker run --rm cbr-cli --no-export
```

## Локальный запуск

```bash
python -m venv .venv
.venv\Scripts\activate           # Windows  (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
python -m cbr_cli --format json --top 5
```

## Аргументы командной строки

| Аргумент | Назначение | По умолчанию |
|---|---|---|
| `--format {csv,json}` | Формат файла экспорта | `csv` |
| `--output PATH` | Путь файла экспорта | `output/cbr_rates_<дата>.<формат>` |
| `--top N` | Размер топа движений | `5` |
| `--no-export` | Не сохранять файл, только консоль | выкл. |
| `--verbose` | Подробное логирование (DEBUG) | выкл. |

## Коды возврата

| Код | Значение |
|---|---|
| `0` | Успех |
| `1` | API недоступен (сеть/таймаут/5xx после retry) |
| `2` | Некорректный формат ответа API |
| `3` | Непредвиденная ошибка |
