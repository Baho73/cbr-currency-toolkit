# Task 3 — Apps Script: курсы валют ЦБ РФ в Google Таблице

Google Apps Script, который обращается к публичному API ЦБ РФ, разбирает
JSON-ответ и записывает обработанные курсы валют в столбцы Google Таблицы.

## Что делает

- По триггеру обращается к `https://www.cbr-xml-daily.ru/daily_json.js` через `UrlFetchApp`.
- Разбирает JSON, считает по каждой валюте суточное изменение (абсолютное и в %).
- Записывает курсы в структурированном виде по столбцам, отсортированные по коду.
- Пишет статус выполнения (успех/ошибка + время) в отдельную ячейку.

## Структура (4 файла `.gs`)

| Файл | Модуль | Ответственность |
|---|---|---|
| `Config.gs` | Config | Замороженный объект констант: URL, имя листа, заголовки, разметка |
| `CbrService.gs` | CbrService | Запрос через `UrlFetchApp`, проверка кода ответа, парсинг и валидация JSON |
| `SheetWriter.gs` | SheetWriter | Запись курсов по столбцам и обновление ячейки статуса |
| `Main.gs` | Main | Кастомное меню `onOpen`, оркестрация `updateRates`, обработка ошибок |

## Триггеры

1. **Кастомное меню (основной).** При открытии таблицы simple-триггер `onOpen`
   добавляет меню **«Курсы ЦБ РФ → Обновить курсы»**. Пункт меню вызывает `updateRates`.
2. **Time-driven (опциональный).** Для автоматического обновления раз в сутки —
   см. установку ниже. Запускается та же функция `updateRates`.

## Логика обработки

API отдаёт по каждой валюте `Value` (курс) и `Previous` (курс на прошлую дату).
Скрипт считает производные значения: `delta_abs = Value − Previous` и
`delta_pct = delta_abs / Previous × 100` (с защитой от деления на ноль).
Валюты сортируются по коду; запись в лист выполняется пакетно одним `setValues`.

## Обработка ошибок

`UrlFetchApp` вызывается с `muteHttpExceptions: true` — код ответа проверяется
вручную. Любой сбой (недоступность сети, код ≠ 200, некорректный JSON,
отсутствие объекта `Valute`) бросает `Error` с понятным текстом. `updateRates`
ловит исключение и записывает текст ошибки и время в ячейку статуса `A1`
(красным цветом) — ошибка видна пользователю, выполнение не падает «тихо».

## Установка

1. Создайте новую Google Таблицу.
2. Меню **Расширения → Apps Script** — откроется редактор скриптов.
3. Создайте 4 файла скрипта (кнопка **+ → Скрипт**) с именами `Config`,
   `CbrService`, `SheetWriter`, `Main` и вставьте содержимое одноимённых
   `.gs`-файлов из этой папки.
4. Сохраните проект (Ctrl+S).
5. Обновите вкладку с таблицей — появится меню **«Курсы ЦБ РФ»**.
6. Нажмите **Курсы ЦБ РФ → Обновить курсы**. При первом запуске Google
   попросит выдать разрешения — подтвердите.

### Установка триггера по расписанию (опционально)

В редакторе Apps Script: **Триггеры** (значок будильника слева) → **+ Добавить
триггер** → функция `updateRates`, источник события **«Триггер по времени»**,
тип — например, **«Таймер по дням»**. Сохранить.

## Доступ к таблице

Для проверки «снаружи» откройте доступ к таблице на просмотр:
**Настройки доступа → Доступные пользователям, у которых есть ссылка → Читатель**.
Код скрипта виден через **Расширения → Apps Script**.
